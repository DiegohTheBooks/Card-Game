# Sistema de Evolução Visual

A evolução das cartas é visual, semelhante a skins de RPG. Não há necessidade de criar níveis numéricos para cada carta.

## Objetivos

- valorizar a coleção;
- permitir versões visuais da mesma personagem;
- preservar a identidade do personagem;
- evitar progressão obrigatória de atributos;
- separar equilíbrio de jogo e raridade visual.

Uma evolução visual pode alterar arte, moldura, acabamento ou apresentação sem obrigatoriamente alterar ATK, DEF ou mana.
